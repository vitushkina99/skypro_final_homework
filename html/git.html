Git

  • git init - Создание нового репозитория.
  • git cd - расшифровывается как "Change directory", что переводится как "сменить папку" или "перейти в другую папку".
  • git pwd - расшифровывается как "Print working directory", что переводится как "текущая рабочая директория". То есть команда git pwd показывает, в какой сейчас папке мы находимся.
  • git log - позволяет просматривать и отслеживать внесенные изменения.
  • git mv - расшифровывается как "Move", что переводится как "переместить", "передвинуть". С помощью нее можно переместить или переименовать файл
